## Cutover checklist inputs (collected while building; used by Plan 7)

Set on Vercel project `droneviet-api` (production) before the single deploy:
- `COOKIE_DOMAIN=.droneviet.vn`
- `CONTENT_PUBLISH_TOKEN` (new random secret; also Keychain `DRONEVIET_CONTENT_TOKEN`)
- `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET=droneviet-media` (Keychain `DRONEVIET_R2_*`) — the API refuses to boot in production without them
- `WEB_REVALIDATE_URL=https://www.droneviet.vn/api/revalidate`, `WEB_REVALIDATE_SECRET` (same secret on `droneviet-vn`)
- `RUN_SEED=1` for the cutover build only (runs `seed-v2` + `seed-admin`), then remove it

Local dev: integration tests run against `droneviet_test` (`TEST_DATABASE_URL=postgres://droneviet:droneviet@localhost:5433/droneviet_test`), never the dev database.

Known follow-ups from Plan 1's review: web must always pass `?kind=` to `/catalog/products` (course products are otherwise listed); treat 401 as "sign in" and 403 as "not allowed".

## Plan 4 pre-work findings (2026-11-23, plan not yet written)

Backend gaps the admin UI needs before the web pages:
- `ContentTokenGuard` (articles + media) reads only the Bearer header; switch it to `readSessionToken()` so the admin's `dv_session` cookie works.
- Missing admin endpoints: `GET/PATCH /admin/quotes` (status new|qualified|sent|converted|lost; roles sales+super_admin), courses admin (list with sessions/enrollments, create/patch session, patch enrollment status reserved|confirmed|cancelled; roles instructor+super_admin), `GET /admin/media` list.
- Already there: `/admin/catalog/*` (products list/patch, variants patch incl. stock, combo-items, size-tiers, create, publish), `/admin/orders` (list, `POST :id/transition {nextStatus}`), `PATCH /admin/settings/contact|announcement`, `POST /admin/media`, `/admin/content/articles` (list, PUT, publish, unpublish).
Web: `/admin` client shell gated by staff roles (signed out → `/dang-nhap?tiep=/admin`, customer → "Không có quyền"), pages: Tổng quan, Sản phẩm & combo, Đơn hàng, Báo giá, Khóa học, Bài viết, Media, Cài đặt.
