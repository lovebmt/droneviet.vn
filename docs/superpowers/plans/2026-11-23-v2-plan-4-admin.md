# v2 Plan 4 — Admin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Staff manage products and combos, orders, quotes, courses, articles, media and site settings from `/admin` without a deploy.
**Architecture:** Client-rendered admin under `/admin` using the `dv_session` cookie via `apiFetch`; backend adds the missing admin endpoints. Every write that changes public pages already calls `WebRevalidator` (catalog, content) or is admin-only data.
**Tech Stack:** NestJS 10 + TypeORM, Next.js 16 client components, Vitest.
**Spec:** `docs/superpowers/specs/2026-11-23-droneviet-v2-rewrite-design.md` §10, §9.

## Global Constraints
- Branch `rewrite/v2`, no deploy. Design tokens and copy rules from Plan 2 apply (sentence case, no "›/→", Lucide icons).
- Roles: super_admin everything; catalog_manager catalog + media + articles; operations orders; sales quotes; instructor courses. 401 → sign in, 403 → "Không có quyền".
- Backend tests use `droneviet_test`; web tests as in Plan 3.

## Review Focus
1. A customer (no staff role) opens `/admin` → "Không có quyền truy cập", no admin data requested. → Task 2
2. Signed-out visitor opens `/admin/...` → `/dang-nhap?tiep=/admin/...`. → Task 2
3. Admin cookie (not Bearer) can list articles and upload media. → Task 1
4. Price/stock input that is negative or empty → API 400 shown as a message; nothing saved. → Task 3
5. Order transition not allowed by the workflow → API error shown, list unchanged. → Task 4

### Task 1: Backend admin gaps
**Files:** `backend/src/auth/content-token.guard.ts`; `backend/src/quotes/admin-quotes.controller.ts`; `backend/src/courses/admin-courses.controller.ts`; `backend/src/media/admin-media.controller.ts`; integration spec `backend/src/admin-v2.integration.spec.ts`.
**Produces:** guard reads `readSessionToken()`; `GET /admin/quotes?status` (newest first), `PATCH /admin/quotes/:id {status}` (sales, super_admin); `GET /admin/courses` (courses with sessions: id, startsAt, capacity, reservedSeats, status, enrollments count), `POST /admin/courses/:slug/sessions {startsAt, capacity}`, `PATCH /admin/course-sessions/:id {capacity?, status?}`, `GET /admin/course-sessions/:id/enrollments`, `PATCH /admin/enrollments/:id {status}` (instructor, super_admin; revalidates `courses`); `GET /admin/media` newest first (super_admin, catalog_manager).
- Tests: `admin cookie can list articles`; `customer cookie is 401 on admin articles`; `sales lists and updates quotes, customer gets 403`; `instructor creates a session and confirms an enrollment`; `media list returns uploaded files`. Commit `feat(api): admin endpoints for quotes, courses and media`.

### Task 2: Admin shell
**Files:** `src/app/admin/{layout.tsx,page.tsx}`, `src/components/admin/{admin-gate.tsx,admin-nav.tsx,use-admin.ts}`; tests.
**Produces:** `AdminGate` (signed-out → sign-in with `tiep`; no staff role → "Không có quyền truy cập"); nav filtered by role; overview with counts (new quotes, orders awaiting action, draft articles) from the list endpoints; `useAdminData<T>(path)` hook {data, error, reload}.
- Tests: `customer sees no-access and no admin request`; `signed-out goes to sign-in`; `nav shows only sections the role allows`. Commit `feat(web): admin shell and overview`.

### Task 3: Products & combos
**Files:** `src/app/admin/san-pham/{page.tsx,[id]/page.tsx}`, `src/components/admin/{product-form.tsx,variant-row.tsx,combo-editor.tsx,image-upload.tsx}`; tests.
**Produces:** list with search + kind filter + status; edit page: name, summary, badge, levels, featured, status, cover image (upload → `/admin/media` → url), gallery, specs (simple group/label/value rows), FAQ, variants (price, compare-at, stock) each saved with PATCH; combos also edit combo items (product + qty) and size tiers (students + price).
- Tests: `saving a variant sends price and stock`; `API 400 shows the message and keeps the input`; `combo editor sends items and tiers`. Commit `feat(web): admin products and combos`.

### Task 4: Orders & quotes
**Files:** `src/app/admin/don-hang/page.tsx`, `src/app/admin/bao-gia/page.tsx`, `src/components/admin/order-actions.tsx`; tests.
**Produces:** orders table (status filter, detail drawer: lines, contact, address) with allowed next-status buttons; quotes table with status select and contact links (tel, Zalo, mailto).
- Tests: `order transition posts nextStatus and refreshes`; `a rejected transition shows the error`; `quote status change patches the quote`. Commit `feat(web): admin orders and quotes`.

### Task 5: Courses, articles, media, settings
**Files:** `src/app/admin/{khoa-hoc,bai-viet,media,cai-dat}/page.tsx`; tests.
**Produces:** courses with sessions (add session, capacity, open/close) and enrollments (confirm/cancel); articles list with publish/unpublish and preview link (writing stays in the skill); media library (upload, copy URL, alt); settings forms for contact and announcement.
- Tests: `add session posts startsAt and capacity`; `unpublish calls the API`; `settings save contact fields`. Commit `feat(web): admin courses, articles, media and settings`.
